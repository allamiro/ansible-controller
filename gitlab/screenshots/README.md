# GitLab walkthrough screenshots

Captured from the local GitLab Community Edition lab on 2026-09-09 at a
1440 × 1000 browser viewport. These PNG files are used by
[the walkthrough](../STEP-BY-STEP.md).

Screens show the sign-in page, empty account/project forms, existing membership,
repository, pipeline 33, manual job 67, successful job 70 and an empty tag form.
The new-project form has README initialization cleared. The manual-job Variables
section is expanded to show its warning. No account, project, tag or deployment
was created while capturing these screens. Passwords and authentication tokens
are not included.

These are historical UI examples, not current configuration guarantees. In
particular, job 70 had a console trace but no downloadable result archive. Root
is shown for the administrative capture; operators should use named accounts.
To refresh, capture the equivalent pages in a trusted lab browser without
submitting forms, check for credentials/private data, and review the images
before committing them. Do not capture private state files or revealed CI secrets.
